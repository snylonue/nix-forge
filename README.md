# nix-forge

Minecraft **Forge** server packages for [nix-minecraft][nix-minecraft].

this covers some versions of 1.12.2,
1.16.5, 1.18.2 and 1.20.1.

## Use

### legacyPackages

```sh
# flake.nix
inputs.nix-forge.url = "github:snylonue/nix-forge";

#...
inputs.nix-forge.legacyPackages.<system>.forge-1_20_1-47_4_20
```

### Overlay

To use it inside another configuration:

```nix
# flake.nix
inputs.nix-forge.url = "github:snylonue/nix-forge";

# then
{
  # remember to allow unfree
  nixpkgs.overlays = [ inputs.nix-forge.overlays.forge-servers ];
}
```

```nix
# forge-1_20_1       tracks the latest locked build for 1.20.1
# forge-1_20_1-47_4_20  pins one build
pkgs.forgeServers.forge-1_20_1
```

### With nix-minecraft's module

```nix
services.minecraft-servers = {
  enable = true;
  eula = true;
  servers.myserver = {
    enable = true;
    package = pkgs.forgeServers.forge-1_20_1;
    jvmOpts = "-Xmx4G";
  };
};
```

## Add or update a version

Locks are generated by `update.py`, which needs network access:

```sh
nix run .#update-forge -- 1.20.1 47.4.20   # one version
nix run .#update-forge  # refresh every lock in locks/
```

`http_proxy` / `https_proxy` are honoured. Any 1.13–1.20.x version should work
without code changes.

## Layout

```
flake.nix                  overlay `forge-servers`, `nix run .#update-forge`
pkgs/forge-servers/
  default.nix              one attribute per lock
  derivation.nix           the build
  update.py                lock generator
  run-processors.py        runs install_profile.json's processors directly
  prune.py                 strips install residue
  locks/                   one JSON per locked version
```
